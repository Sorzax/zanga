# زنقة الكلاب

مشروع مذاكرة تفاعلية بالعربي والإنجليزي، مكتوب بـ HTML وCSS وJavaScript عادي. فيه 6 مواد، و185 درسًا، و1976 سؤالًا ظاهرًا للتدريب، مع المختبرات ومولّدات الأسئلة الموجودة في النسخة الأصلية.

## التشغيل

فكّ ضغط المجلد كاملًا، ثم افتح `index.html` بالنقر المباشر. حزمة التشغيل جاهزة داخل `assets/js/runtime/`، وتعمل أيضًا عبر Live Server والاستضافة الثابتة.

أو إذا عندك Node.js 20 أو أحدث، افتح الطرفية داخل المجلد:

```bash
npm run dev
```

افتح الرابط الذي يظهر في الطرفية. ما تحتاج `npm install`؛ المشروع بدون حزم خارجية. أمر التطوير يعيد تجهيز حزمة التشغيل تلقائيًا.

بعد تعديل ملفات JavaScript أو محتوى المواد، شغّل `npm run build` قبل فتح النسخة المعدّلة بالنقر المباشر أو رفعها إلى الاستضافة. ملفات `runtime/` مولّدة؛ عدّل الملفات المقسّمة في `core/` و`features/` و`subjects/` و`data/`، ثم أعد البناء. لتعديل هيكل الصفحة، استخدم `index.template.html`؛ أمر البناء ينتج `index.html` منه ويضع بطاقات المواد داخله مسبقًا.

## وين أعدل؟

| المطلوب | المكان |
| --- | --- |
| هيكل الصفحة القابل للتعديل | `index.template.html` ثم `npm run build` |
| ملفات التشغيل الجاهزة | `index.html` و`assets/js/runtime/` |
| الألوان وأسماء المواد | `data/catalog.js` |
| محتوى الدروس والأسئلة والتشبيهات | `data/subjects/اسم-المادة.js` |
| تنسيق الواجهة | `assets/css/` |
| حفظ التقدم ومفاتيحه | `assets/js/core/state.js` و`storage.js` |
| منطق الأسئلة والنتائج | `assets/js/features/quiz.js` |
| الخطط والدروس والأخطاء | `assets/js/features/` |
| مختبرات المواد ومولّدات أسئلتها | `assets/js/subjects/` |
| التنقل والتبويبات | `assets/js/ui/navigation.js` |
| المؤثرات القصيرة والصوت | `assets/js/core/effects.js` |
| عميل السكوربورد المستقبلي | `assets/js/services/leaderboard.js` و`config/api.js` |

اختصارات المواد: `net` شبكات، `os` نظم تشغيل، `algo` خوارزميات، `web` ويب، `pl` لغات برمجة، `sc` بناء برمجيات.

## التعديلات المنفّذة

- فصل محتوى كل مادة عن منطق الواجهة والمختبرات.
- تشغيل الصفحة بالنقر المباشر باستخدام سكربتات عادية، مع بقاء مصادر التطوير مقسّمة إلى وحدات.
- وضع بطاقات المواد الست في HTML قبل بدء JavaScript، وإظهار حالة تحميل واضحة عند تعطل أحد ملفات التشغيل.
- تحميل المادة عند فتحها؛ الصفحة الرئيسية لا تنزّل بنوك أسئلة المواد الست.
- إزالة خلفية الـCanvas المتحركة وحلقة الرسم المستمرة، مع إبقاء ألوان المواد ومؤثرات الإجابة القصيرة.
- تنظيف هيكل HTML وإضافة لغة الصفحة واتجاهها ووصفها وأيقونتها.
- دعم زر رجوع المتصفح والتنقل بين المواد، مع معالجة فشل تحميل المادة.
- الحفاظ على مفاتيح `uz_*` القديمة وترتيب الأسئلة، وتنظيف بيانات الحفظ غير الصالحة.
- إصلاح تكرار إنهاء الاختبار عند مراجعة نتيجته، وحماية إدخال النصوص داخل خصائص HTML.
- تحسين تنسيق الشاشة الضيقة والتنقل بين التبويبات بلوحة المفاتيح.

## الصور

المرفق كان ملف HTML واحدًا ويشير إلى 307 صور داخل `img/`، والصور نفسها لم تكن ضمن المرفق. أضف **مجلد `img` الأصلي** بجانب `index.html`؛ المسارات محفوظة. توجد قائمة الأسماء في `docs/slide-assets.txt`. إلى أن تضيف الصور، يعرض الموقع رسالة مكان الصورة المفقودة ويواصل عرض الدرس والأسئلة.

## التحديث على الاستضافة الحالية

ارفع `index.html` و`assets/` و`data/` و`config/` مع `img/` إلى نفس مجلد النشر. استبدل الملفات المتطابقة مع الاحتفاظ بمجلد صورك. لا ترفع `index.html` وحده بعد التقسيم. ملفات `tests/` و`scripts/` و`docs/` للتطوير وليست مطلوبة لتشغيل الموقع المنشور.

الواجهة Static وملفات تشغيلها مبنية مسبقًا في الحزمة. إذا عدّلت مصادرها، شغّل `npm run build` ثم ارفع المحتويات داخل مجلد النشر المختار في مشروعك؛ ملف `.nojekyll` موجود. تحديث الموقع على **نفس النطاق والبروتوكول** يحافظ على تقدم المتصفح القديم. التقدم لا ينتقل تلقائيًا بين الأجهزة أو النطاقات، ودعم التخزين للملفات المحلية يخضع للمتصفح.

## السكوربورد والباك إند

النقاط الحالية شخصية ومحفوظة في المتصفح. لا يوجد حساب مستخدم أو ترتيب عام أو باك إند يعمل ضمن هذه الحزمة. توجد خطة Java/Spring Boot + PostgreSQL وخوارزمية منح النقاط ومنع تكرارها وعقد الـAPI في `docs/leaderboard-backend.md`. عميل القراءة جاهز ومقفول افتراضيًا إلى أن تشغّل الباك إند.

## الفحص

```bash
npm run check
npm test
```

الفحص يتحقق من صياغة JavaScript ومسارات الاستيراد، والاختبارات تتحقق من تطابق المحتوى الأصلي والخطط والحفظ والأسئلة المولّدة وعميل السكوربورد. تفاصيل ما جُرّب موجودة في `docs/verification.md`.
