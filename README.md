# زنقة الكلاب

مشروع مذاكرة تفاعلية بالعربي والإنجليزي، مكتوب بـ HTML وCSS وJavaScript عادي. فيه 6 مواد، و185 درسًا، و1976 سؤالًا ظاهرًا للتدريب، مع المختبرات ومولّدات الأسئلة الموجودة في النسخة الأصلية.

## التشغيل

فكّ ضغط المجلد كاملًا، ثم افتح `index.html` بالنقر المباشر. حزمة التشغيل جاهزة داخل `assets/js/runtime/`، وتعمل أيضًا عبر Live Server والاستضافة الثابتة.

أو إذا عندك Node.js 20 أو أحدث، افتح الطرفية داخل المجلد:

```bash
npm run dev
```

افتح الرابط الذي يظهر في الطرفية. ما تحتاج `npm install`؛ المشروع بدون حزم خارجية. أمر التطوير يعيد تجهيز حزمة التشغيل تلقائيًا.

بعد تعديل ملفات JavaScript أو محتوى المواد، شغّل `npm run build` قبل فتح النسخة المعدّلة بالنقر المباشر أو رفعها إلى الاستضافة. ملفات `runtime/` مولّدة؛ عدّل الملفات المقسّمة في `core/` و`features/` و`subjects/` و`data/`، ثم أعد البناء. لتعديل هيكل الصفحة، استخدم `index.template.html`؛ أمر البناء ينتج `index.html` منه ويضع بطاقات المواد داخله مسبقًا.

## وين أعدل؟

| المطلوب | المكان |
| --- | --- |
| هيكل الصفحة القابل للتعديل | `index.template.html` ثم `npm run build` |
| ملفات التشغيل الجاهزة | `index.html` و`assets/js/runtime/` |
| الألوان وأسماء المواد | `data/catalog.js` |
| محتوى الدروس والأسئلة والتشبيهات | `data/subjects/اسم-المادة.js` |
| تنسيق الواجهة | `assets/css/` |
| حفظ التقدم ومفاتيحه | `assets/js/core/state.js` و`storage.js` |
| منطق الأسئلة والنتائج | `assets/js/features/quiz.js` |
| الخطط والدروس والأخطاء | `assets/js/features/` |
| مختبرات المواد ومولّدات أسئلتها | `assets/js/subjects/` |
| التنقل والتبويبات | `assets/js/ui/navigation.js` |
| المؤثرات القصيرة والصوت | `assets/js/core/effects.js` |
| عميل السكوربورد المستقبلي | `assets/js/services/leaderboard.js` و`config/api.js` |

اختصارات المواد: `net` شبكات، `os` نظم تشغيل، `algo` خوارزميات، `web` ويب، `pl` لغات برمجة، `sc` بناء برمجيات.
