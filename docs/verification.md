# التحقق من النسخة المرتبة

تاريخ الفحص: 2 نوفمبر 2026.

## الفحص الآلي

الأوامر: `npm run check` و`npm test`.

- 31 حالة اختبار: تطابق محتوى المواد الأصلية، ومولّدات الأسئلة، والخطط، والحفظ القديم، والتعامل مع البيانات التالفة، وعميل الترتيب، ودورة إنهاء الاختبار ومراجعته، وحزمة المتصفح المبنية.
- اختبار تشغيل الحزمة المبنية داخل بيئة DOM معزولة بعناوين `file:` و`https:`، يشغّل النواة وسكربتات المواد الست فعليًا دون محمّل ES Modules أو `fetch`، ويختبر الرجوع للرئيسية والتعافي من فشل تحميل مادة.
- اختبار يثبت وجود بطاقات المواد الست في HTML قبل بدء JavaScript، وغياب `type="module"` و`import()` من مسار تشغيل المتصفح.
- بصمات محتوى الدروس والأسئلة والشروحات والصور والشابترات تطابق النسخة الأصلية بعد تهيئتها. لا تتضمن هذه المطابقة مراجعة علمية لصحة محتوى المادة.
- اختبارات الخطط تغطي 1 و2 و3 و7 و14 و30 و90 يومًا لكل مادة، وتتحقق من ظهور كل درس مرة واحدة وبترتيبه، ووجود البروفة النهائية.
- فحص صياغة ملفات JavaScript ومسارات الاستيراد والملفات المرتبطة من `index.html`.

جُرّب في كل مادة: فتح الدروس والدرس الأول، وإجابة خاطئة مع شرحها، وظهور السؤال في «أخطائي»، وفتح المختبر، والاختبار المخصص، واختبار الشابتر، وملخص زنقة الكلاب، والانتقال من أهم النقاط إلى التدريب.

جُرّبت الصفحة الرئيسية ودرس الشبكات داخل إطار بعرض 390 بكسل، ومساحة محتوى فعلية 375 بكسل، دون زيادة عرض الصفحة أو تمرير أفقي. هذا فحص تخطيط ضيق داخل متصفح سطح المكتب، وليس اختبارًا على هاتف حقيقي.

لم تظهر أخطاء JavaScript من التطبيق في المسارات المجربة. ظهرت طلبات 404 لصور السلايدات الغائبة؛ الواجهة تعرض الرسالة البديلة المقصودة.

## ما يحتاج إكمالًا خارجيًا

- استرجاع مجلد `img` الأصلي: 307 صور غير مرفقة. القائمة في `slide-assets.txt`.
- تشغيل باك إند وحسابات وقاعدة بيانات لبناء ترتيب عام؛ الخطة في `leaderboard-backend.md`، والعميل مقفول افتراضيًا. اختبارات العميل تستخدم ردودًا وهمية داخل الاختبار فقط.
- رفع الحزمة إلى الاستضافة الفعلية وتجربة نطاقها. لم يُعدّل مستودع خارجي أو موقع منشور ضمن هذا الطلب.
- سياسة متصفح الفحص تمنع فتح `file://`، لذلك لم يُجرَ فحص بصري مباشر لملف محلي. فحص هذا المسار تشغيلي في بيئة DOM معزولة، وفحص الواجهة الفعلي عبر خادم المعاينة.
- المختبرات جرى فتحها وفحص مسارات ممثلة منها؛ لم تُختبر يدويًا كل مسألة وكل تركيب إدخال ممكن.
